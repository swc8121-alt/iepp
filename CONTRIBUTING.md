# Contributing to IEPP

IEPP is early-stage security research. Contributions that clarify assumptions, reproduce experiments, identify attacks, or narrow claims are especially valuable.

## Ground rules

1. Distinguish empirical results from formal security claims.
2. State the attacker model and evidence level.
3. Include failed hypotheses and negative controls.
4. Do not publish secrets, raw protected state, personal data, patent-confidential material, or credentials.
5. Preserve attribution and the history of existing experiments.

## Suggested contribution types

- specification review;
- attack-model critique;
- independent experiment reproduction;
- VM snapshot and rollback tests;
- TPM, TEE, PUF, or monotonic-counter integration;
- registry consistency and transparency designs;
- privacy and selective-disclosure analysis.

## Pull requests

Keep changes focused. Explain the claim affected, the threat model, test method, result, limitation, and reproducibility steps. Security-relevant changes should remain draft until reviewed.
