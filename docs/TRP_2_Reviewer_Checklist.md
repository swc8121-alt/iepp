# TRP 2.0 Reviewer Checklist

Before accepting a TRP result or claim, verify:

- [ ] The canonical-success event is defined.
- [ ] The compromise boundary is stated.
- [ ] The adversary view/capability class is stated.
- [ ] The evidence level is stated.
- [ ] Registry consistency/atomicity assumptions are stated.
- [ ] Entropy properties are not inferred from uniqueness alone.
- [ ] Fork divergence is not presented as proof of originality.
- [ ] Key+state compromise is not silently excluded when relevant.
- [ ] Trial count and attack budget are reported for empirical tests.
- [ ] Zero observed successes is not described as mathematical impossibility.
- [ ] Negative controls and known limitations are included.
- [ ] A theorem/hardness claim is backed by an actual formal proof or clearly labeled conjectural.
