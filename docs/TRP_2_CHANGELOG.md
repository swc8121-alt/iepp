# TRP 2.0 change log

## v0.1 — 2026-08-10

- Reframed TRP as the Canonical Continuation Security Game.
- Added explicit adversary view and A0–A6 capability hierarchy.
- Defined unauthorized canonical acceptance as the primary success event.
- Separated execution/fork divergence from canonical selection.
- Made current-state + signing-key compromise an explicit L1 boundary control.
- Added required claims discipline for invariants, assumptions, empirical results and conjectures.
- Added a 12-case adversarial validation plan.
- Added a dependency-free executable bounded model and regression tests.
- Added a GitHub Actions workflow for the bounded TRP 2.0 security game.
